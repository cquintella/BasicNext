# Basic Next 0.3 Host Capability Evidence

## Current target

The executable target for this release audit is `aarch64-apple-darwin` with
Rust 1.97.0. macOS has no approved unprivileged ICMP provider in D-016, so the
runtime deliberately returns typed `operation-unavailable` results for
`HOST.Net.Ping` and `HOST.Net.Neighbor`. TCP, UDP, address parsing, CIDR, and
resolver operations remain available independently.

The executable test `host_net_optional_providers_fail_deterministically_when_unavailable`
proves both optional operations return `Error` without disabling `HOST.Net`.
No Linux or Windows support claim is made without host-specific evidence.

## IPsec

Basic Next exposes no IPsec API. This macOS build makes no transparent IPsec
support claim; ordinary TCP/UDP behavior is the only supported network claim.
