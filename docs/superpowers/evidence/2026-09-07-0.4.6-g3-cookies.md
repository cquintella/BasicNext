## 1. Activities Summary

* **Activity 3.1: Serialize typed cookie -> `Set-Cookie`**
  * Added `CookieOptions::format_set_cookie(&self, name: &str, value: &str, domain: Option<&str>, path: &str, max_age: Option<Duration>) -> Result<String, &'static str>` in `src/web_state.rs`.
  * Serializes typed properties: `Path`, optional `Domain`, optional `Max-Age` in seconds, `Secure`, `HttpOnly`, and `SameSite` (`Strict`, `Lax`, or `None`).
  * Validates bounds and control characters to prevent header injection.

* **Activity 3.2: Reject `Secure` cookies on cleartext responses**
  * Added `Response::set_cookie(...)` in `src/web.rs`.
  * Verifies transport security: if `options.secure && !is_tls`, the request fails immediately with `Err("Secure cookies cannot be sent over cleartext HTTP")`.
  * Preserves safe defaults: `CookieOptions::default()` has `secure: true, http_only: true, same_site: SameSite::Lax`.

* **Activity 3.3: Set / clear / rotate session ID as HTTP headers**
  * Added `Response::set_session_cookie` and `Response::clear_cookie` on `Response` in `src/web.rs`.
  * Unit tests in `src/web_state.rs` assert:
    * Cookie header formatted on create: `Set-Cookie: sid=<id>; Path=/; ...; Max-Age=900; Secure; HttpOnly; SameSite=Lax`.
    * Rotated session ID replaces header on rotate.
    * Deleted session issues deletion cookie with `Max-Age=0`.
  * Integration test in `src/http/tests.rs` asserts cookies transmit over local HTTP/1.1 connections.
