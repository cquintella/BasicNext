# Bucket 0.4.5 — Shared type leaf for IR consumers

Date: 2026-09-06

## Implemented

- Added `src/types.rs` as the definition site for `Type`, `IntegerType`, `FloatType`, `PointerLength`, and `ModuleId`.
- `semantic` re-exports the types for existing frontend callers.
- `ir::model`, LLVM, and runtime value consumers use the shared definitions directly instead of importing semantic types.
- `ir::Type` and the related scalar types are publicly re-exported as the IR-facing API.

This removes the semantic-type edge from the current in-tree IR model and backend consumers. It does not close GC-DEP yet: lowering is still colocated in the root crate and the workspace crate cut remains pending.
