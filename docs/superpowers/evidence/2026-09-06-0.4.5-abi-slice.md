# Bucket 0.4.5 — ABI slice

Date: 2026-09-06

The release-slice ABI contract now records concrete representations and
ownership for scalar values, strings crossing HOST calls, dispatch values and
errors, and opaque handles. `bn_rt` tests assert the C layout offsets and
alignment without assuming a fixed pointer width.

Verification:

```text
cargo test --package bn_rt dispatch_abi::tests::c_abi
2 passed
cargo test -p bn_rt
not fully runnable in the current sandbox: 9 network tests fail at loopback
bind with `Operation not permitted`, and subsequent tests observe the poisoned
network-test mutex. The non-network ABI/policy/clock tests pass separately:
dispatch_abi (9), policy (2), and the two clock tests (2).
cargo clippy --all-targets -- -D warnings
passed
```

This is a GC-ABI slice, not closure of every `bn_rt` symbol. Native BNData/
DataFrame bindings and the complete network ownership inventory remain open.
The loopback test result must be rerun in an environment that permits local
socket binding before the full ABI gate can be considered verified.
