# Basic Next Language Specification 0.1 (rascunho)

Esta especificação define o núcleo necessário para programas pequenos. Tudo
que não estiver aqui não é parte da linguagem 0.1.

## Léxico

O código-fonte é Unicode em UTF-8. Espaços e tabulações separam tokens; fim de
linha separa comandos. Não há continuação de linha na 0.1.

Identificadores começam por letra ASCII ou `_` e continuam com letras ASCII,
dígitos ou `_`. São case-insensitive: `contador`, `Contador` e `CONTADOR`
referem-se ao mesmo nome. Palavras reservadas também são case-insensitive e não
podem ser usadas como identificadores.

Comentários de linha começam com `'` e terminam no fim da linha. Strings usam
aspas duplas, não podem atravessar linhas e aceitam apenas os escapes `\"` e
`\\`. Literais inteiros são sequências decimais de dígitos; literais de ponto
flutuante possuem ponto decimal, como `3.14`.

### Palavras reservadas

```text
AND       AS        BOOLEAN   CLASS     CONST     ELSE
END       FALSE     FLOAT     FOR       FUNCTION  HOST
IMPORT    INTEGER   LET       MOD       NEXT      NOT
OR        PRINT     REPEAT    RETURN    STRING    SUB
SYSTEM    THEN      TO        TRUE      UNTIL     VOID
WHILE
```

### Símbolos

```text
+  -  *  /  =  <>  <  <=  >  >=  +=  -=
(  )  ,
```

O analisador deve reconhecer o maior símbolo válido: por exemplo, `<=` não é
dois tokens (`<` e `=`), e `+=` não é `+` seguido de `=`.

### Gramática estrutural

A notação abaixo usa EBNF: `{x}` significa repetição, `[x]` significa item
opcional e aspas indicam palavras ou símbolos literais. A gramática de
expressões será detalhada na seção de tipos e expressões.

```ebnf
program          = { blank-line | import-declaration | declaration } ;
blank-line       = newline ;
import-declaration = "IMPORT" import-path "AS" identifier newline ;
import-path      = "HOST" "." identifier | identifier "." identifier ;

declaration      = sub-declaration | function-declaration | class-declaration ;
sub-declaration  = "SUB" identifier "(" [ parameters ] ")" newline
                   { statement } "END" "SUB" newline ;
function-declaration = "FUNCTION" identifier "(" [ parameters ] ")" "AS" type newline
                   { statement } "END" "FUNCTION" newline ;
class-declaration = "CLASS" identifier newline
                   { sub-declaration | function-declaration }
                   "END" "CLASS" newline ;

parameters       = parameter { "," parameter } ;
parameter        = identifier "AS" type ;
type             = "BOOLEAN" | "INTEGER" | "FLOAT" | "STRING" | "VOID" ;
statement        = { non-newline-character } newline ;
identifier       = ( letter | "_" ) { letter | digit | "_" } ;
letter           = "A"…"Z" | "a"…"z" ;
digit            = "0"…"9" ;
non-newline-character = ? qualquer caractere exceto terminador de linha ? ;
newline          = "\\n" | "\\r\\n" ;
```

`statement` é propositalmente aberto nesta seção; as formas completas dos
comandos aparecem nas seções de expressões e controle de fluxo.

## Tipos

Tipos primitivos: `BOOLEAN`, `INTEGER`, `FLOAT`, `STRING` e `VOID`.

Declarações usam `nome AS TIPO`. `LET nome = expressão` infere o tipo da
expressão; `LET nome AS TIPO = expressão` exige atribuição compatível. `CONST`
segue a mesma forma e não pode ser reatribuído.

## Programa e declarações

Uma unidade de compilação contém `IMPORT`, `CLASS`, `SUB` e `FUNCTION`. O
módulo executável é a unidade carregada pelo runtime e deve declarar exatamente
um `SUB Start()`; o runtime chama esse método para iniciar o programa. Comandos
não podem aparecer soltos no nível do módulo.

O módulo executável pode declarar `IMPORT HOST.main AS main`. `HOST` representa
o ambiente hospedeiro e `main` é o objeto `SYSTEM` fornecido por ele. Apenas o
módulo executável pode importar `HOST.main`. A interface de `SYSTEM` será
definida separadamente; ela não faz parte da sintaxe ou semântica-base da 0.1.

`SUB` não retorna valor; `FUNCTION` declara um tipo de retorno após `AS`.
Corpos terminam com `END SUB`, `END FUNCTION` ou `END CLASS`.

## Expressões

Literais, identificadores, chamadas e parênteses compõem expressões. Operadores
em ordem decrescente de precedência: unários `NOT`, `-`; multiplicativos `*`,
`/`, `MOD`; aditivos `+`, `-`; comparação `<`, `<=`, `>`, `>=`; igualdade `=`,
`<>`; lógicos `AND`, `OR`.

`+` concatena strings se ambos os operandos forem `STRING`; nos demais casos
é adição numérica. Não há coerção implícita entre `STRING` e números.

## Comandos

Comandos básicos são `LET`, `CONST`, atribuição, `PRINT`, chamada, `RETURN`,
`IF`, `WHILE`, `REPEAT` e `FOR`.

```basic
IF condition THEN
    PRINT "sim"
ELSE
    PRINT "não"
END IF

WHILE condition
    contador += 1
END WHILE

REPEAT
    contador -= 1
UNTIL contador = 0

FOR i AS INTEGER = 0 TO 9
    PRINT i
NEXT
```

`IF`, `WHILE` e `UNTIL` exigem `BOOLEAN`. `WHILE` testa a condição antes do
corpo; `REPEAT` executa o corpo ao menos uma vez e termina quando `UNTIL` for
verdadeiro. `FOR` itera inclusivamente e usa passo `1` na 0.1. `RETURN` em uma
`FUNCTION` exige expressão compatível com o tipo de retorno; em uma `SUB`, não
aceita expressão.

## Ainda em decisão

`MATCH`, `STRUCT`, `ENUM`, `INTERFACE`, módulos, coleções, tratamento de erros
e concorrência precisam de propostas antes de integrar uma versão posterior da
especificação.
