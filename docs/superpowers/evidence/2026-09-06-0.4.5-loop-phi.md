# Bucket 0.4.5 — loop-carried SSA repair

Date: 2026-09-06

## Root cause and implementation

`FOR EACH` previously reused the initial index `ValueId` for the incremented
index in its backedge block. With SSA uniqueness enforced, this was invalid IR.
The lowering now creates an initial value in the preheader, an incremented value
on the backedge, and a loop-index `Phi` in the condition block. If the body
terminates without a backedge (for example, `EXIT FOR`), the `Phi` includes only
the reachable preheader predecessor.
