# Basic Next 0.4.2 Release Notes

Basic Next 0.4.2 is a bug-fix release focused on reliable release verification
and accurate compiler capability reporting.

## Fixes

- Stabilized the HTTP shutdown regression test across platforms and accounted
  for direct worker cleanup in the fixture.
- Corrected BNWeb release fixtures so error-union values are narrowed before
  being passed to native provider methods.
- Kept compiler parity suites limited to programs that are actually supported
  by the LLVM and wasm backends.
- Improved LLVM lowering diagnostics for user-defined function calls by naming
  the callee, source location, enclosing function, and supported alternative.
- Preserved `Start() AS INTEGER` as the native process exit-code contract.

## Known limitations

KMP, general user-defined function calls, dynamic pointer arrays, constant
boolean-branch emission, and identical float formatting remain outside the
current LLVM parity subset. They are covered as deferred capabilities rather
than being reported as successful native builds.

## Verification

The release gate requires Rust tests, strict Clippy, formatting, native build
and execution smoke tests, compiler/wasm parity tests, and actionable negative
diagnostics. CI separates the Rust, native capability, parity, and diagnostic
gates; missing LLVM is reported as a visible failure. The exact commands and
acceptance criteria are tracked in
[`ongoing/bucket-0.4.2.md`](../ongoing/bucket-0.4.2.md).
