# Basic Next 0.3 Public API Proposal (D-005)

This proposal is submitted for approval before implementation. It is subordinate
to the normative 0.3 language documents and freezes the smallest public surface
required by the native `HOST.Net` capability and the external `BNLog` and
`BNWeb` modules. Every `BNXxx` facility, including `BNMath`, `BNData`,
`BNLog`, `BNWeb`, and `BNJson`, is an external module with a `.bn` interface
backed by a Rust provider; none is part of the language core.

## Common rules

- Fallible operations return `T OR Error`; no native exception crosses the BN boundary.
- Returned opaque values are owned by the caller and must be released with `DELETE` when they are class instances.
- `Close` is idempotent. A closed value returns `Error.Code = CLOSED` for every operation except a repeated `Close`.
- Provider, timeout, limit, permission, and malformed-input failures are typed `Error` values.
- Defaults are those in `ongoing/0.3-decisions.md`; hosts may only reduce them.

`Error.Code` is a fixed string-like enum. The 0.3 codes are `INVALID_INPUT`,
`LIMIT`, `TIMEOUT`, `EOF`, `CLOSED`, `UNAVAILABLE`, `PERMISSION_DENIED`,
`UNREACHABLE`, `NOT_FOUND`, `ADDRESS_IN_USE`, `OVERLOADED`,
`ALREADY_COMMITTED`, `CAPABILITY_UNAVAILABLE`, and `IO`. Providers may attach
bounded detail text but may not add new public variants.

## Native capability: `HOST.Net`

```basic
CLASS Address
    PUBLIC STATIC FUNCTION Parse(text AS STRING) AS Address OR Error
    PUBLIC FUNCTION ToString() AS STRING
    PUBLIC FUNCTION IsIPv4() AS BOOLEAN
    PUBLIC FUNCTION IsIPv6() AS BOOLEAN
    PUBLIC FUNCTION IsLoopback() AS BOOLEAN
    PUBLIC FUNCTION IsPrivate() AS BOOLEAN
    PUBLIC FUNCTION IsLinkLocal() AS BOOLEAN
    PUBLIC FUNCTION IsMulticast() AS BOOLEAN
END CLASS

CLASS CIDR
    PUBLIC STATIC FUNCTION Parse(text AS STRING) AS CIDR OR Error
    PUBLIC FUNCTION Network() AS Address
    PUBLIC FUNCTION PrefixLength() AS INTEGER
    PUBLIC FUNCTION Contains(address AS Address) AS BOOLEAN
END CLASS

CLASS Endpoint
    PUBLIC STATIC FUNCTION Create(address AS Address, port AS UINT16) AS Endpoint OR Error
    PUBLIC FUNCTION Address() AS Address
    PUBLIC FUNCTION Port() AS UINT16
END CLASS

CLASS Addresses
    PUBLIC FUNCTION Count() AS INTEGER
    PUBLIC FUNCTION Get(index AS INTEGER) AS Address OR Error
END CLASS

FUNCTION Resolve(host AS STRING, timeoutMs AS INTEGER) AS Addresses OR Error
FUNCTION Reverse(address AS Address, timeoutMs AS INTEGER) AS STRING OR Error

CLASS TCPStream
    PUBLIC FUNCTION Read(buffer AS POINTER TO BYTE[], maximum AS INTEGER) AS INTEGER OR EOF OR Error
    PUBLIC FUNCTION Write(buffer AS POINTER TO BYTE[], count AS INTEGER) AS INTEGER OR Error
    PUBLIC FUNCTION LocalEndpoint() AS Endpoint OR Error
    PUBLIC FUNCTION RemoteEndpoint() AS Endpoint OR Error
    PUBLIC FUNCTION ShutdownRead() AS VOID OR Error
    PUBLIC FUNCTION ShutdownWrite() AS VOID OR Error
    PUBLIC FUNCTION SetTimeouts(readMs AS INTEGER, writeMs AS INTEGER) AS VOID OR Error
    PUBLIC FUNCTION Close() AS VOID OR Error
END CLASS

CLASS TCPListener
    PUBLIC FUNCTION Accept(timeoutMs AS INTEGER) AS TCPStream OR Error
    PUBLIC FUNCTION LocalEndpoint() AS Endpoint OR Error
    PUBLIC FUNCTION Close() AS VOID OR Error
END CLASS

FUNCTION TCPConnect(endpoint AS Endpoint, timeoutMs AS INTEGER) AS TCPStream OR Error
FUNCTION TCPListen(endpoints AS Endpoint[], backlog AS INTEGER) AS TCPListener OR Error

CLASS UDPPacket
    PUBLIC FUNCTION Source() AS Endpoint
    PUBLIC FUNCTION Size() AS INTEGER
    PUBLIC FUNCTION WasTruncated() AS BOOLEAN
    PUBLIC FUNCTION CopyTo(buffer AS POINTER TO BYTE[], maximum AS INTEGER) AS INTEGER OR Error
END CLASS

CLASS UDPSocket
    PUBLIC FUNCTION SendTo(endpoint AS Endpoint, buffer AS POINTER TO BYTE[], count AS INTEGER) AS INTEGER OR Error
    PUBLIC FUNCTION Receive(maximum AS INTEGER, timeoutMs AS INTEGER) AS UDPPacket OR Error
    PUBLIC FUNCTION LocalEndpoint() AS Endpoint OR Error
    PUBLIC FUNCTION Close() AS VOID OR Error
END CLASS

FUNCTION UDPBind(endpoint AS Endpoint) AS UDPSocket OR Error

CLASS PingReply
    PUBLIC FUNCTION Address() AS Address
    PUBLIC FUNCTION RoundTripMicroseconds() AS INT64
END CLASS

FUNCTION Ping(address AS Address, timeoutMs AS INTEGER) AS PingReply OR Error
FUNCTION Neighbor(address AS Address) AS Address OR Error
```

`Ping` uses a host-generated identifier, sequence, and fixed 32-byte payload.
`Neighbor` only reads an existing ARP/NDP entry. Neither operation exposes raw
handles, packets, subprocesses, or table mutation. `TCPListen` starts all
requested endpoints atomically; failure closes every endpoint it opened.

## External module: `BNLog`

```basic
CLASS Fields
    PUBLIC FUNCTION Count() AS INTEGER
    PUBLIC FUNCTION SetString(key AS STRING, value AS STRING) AS VOID OR Error
    PUBLIC FUNCTION SetInteger(key AS STRING, value AS INT64) AS VOID OR Error
    PUBLIC FUNCTION SetBoolean(key AS STRING, value AS BOOLEAN) AS VOID OR Error
    PUBLIC FUNCTION Get(key AS STRING) AS STRING OR Error
END CLASS

CLASS Entry
    PUBLIC FUNCTION WithField(key AS STRING, value AS STRING) AS Entry OR Error
END CLASS

CLASS Transport
    PUBLIC FUNCTION Flush(timeoutMs AS INTEGER) AS VOID OR Error
    PUBLIC FUNCTION Close(timeoutMs AS INTEGER) AS VOID OR Error
END CLASS

CLASS Logger
    PUBLIC STATIC FUNCTION New(label AS STRING) AS Logger OR Error
    PUBLIC FUNCTION AddConsole(minimum AS Level) AS VOID OR Error
    PUBLIC FUNCTION AddFile(path AS STRING, minimum AS Level) AS VOID OR Error
    PUBLIC FUNCTION AddNull(minimum AS Level) AS VOID OR Error
    PUBLIC FUNCTION Child(fields AS Fields) AS Logger OR Error
    PUBLIC FUNCTION Log(level AS Level, message AS STRING, fields AS Fields) AS VOID OR Error
    PUBLIC FUNCTION Flush(timeoutMs AS INTEGER) AS VOID OR Error
    PUBLIC FUNCTION Close(timeoutMs AS INTEGER) AS VOID OR Error
END CLASS
```

`Level` is the fixed enum `ERROR, WARN, INFO, HTTP, VERBOSE, DEBUG, SILLY`.
Console, file, and null transports are attempted in registration order. All
eligible transports are attempted; the first failure is returned. Console
requires `HOST.Console`, file requires `HOST.FileSystem`, and null requires no
host capability. File output is append-only UTF-8.

## External module: `BNWeb`

```basic
CLASS HeaderValues
    PUBLIC FUNCTION Count() AS INTEGER
    PUBLIC FUNCTION Get(index AS INTEGER) AS STRING OR Error
END CLASS

CLASS QueryValues
    PUBLIC FUNCTION Count() AS INTEGER
    PUBLIC FUNCTION Get(index AS INTEGER) AS STRING OR Error
END CLASS

CLASS Request
    PUBLIC FUNCTION Method() AS STRING
    PUBLIC FUNCTION Target() AS STRING
    PUBLIC FUNCTION Headers(name AS STRING) AS HeaderValues OR Error
    PUBLIC FUNCTION Query(name AS STRING) AS QueryValues OR Error
    PUBLIC FUNCTION Body(maximum AS INTEGER) AS STRING OR Error
    PUBLIC FUNCTION PeerAddress() AS Net.Address
    PUBLIC FUNCTION EffectiveClientAddress() AS Net.Address OR Error
END CLASS

CLASS Response
    PUBLIC FUNCTION Status() AS INTEGER
    PUBLIC FUNCTION SetStatus(status AS INTEGER) AS VOID OR Error
    PUBLIC FUNCTION SetHeader(name AS STRING, value AS STRING) AS VOID OR Error
    PUBLIC FUNCTION Write(body AS STRING) AS VOID OR Error
    PUBLIC FUNCTION Commit() AS VOID OR Error
    PUBLIC FUNCTION IsCommitted() AS BOOLEAN
    PUBLIC FUNCTION Close() AS VOID OR Error
END CLASS

CLASS Server
    PUBLIC STATIC FUNCTION New(logger AS Log.Logger) AS Server OR Error
    PUBLIC FUNCTION AddFilter(filter AS FUNCTION(Request, Response) AS VOID OR Error) AS VOID OR Error
    PUBLIC FUNCTION Route(method AS STRING, pattern AS STRING, handler AS FUNCTION(Request, Response) AS VOID OR Error) AS VOID OR Error
    PUBLIC FUNCTION Start(endpoint AS Net.Endpoint) AS VOID OR Error
    PUBLIC FUNCTION StartTLS(endpoint AS Net.Endpoint, config AS TLSConfig) AS VOID OR Error
    PUBLIC FUNCTION Dispatch(request AS Request, response AS Response) AS VOID OR Error
    PUBLIC FUNCTION Stop(timeoutMs AS INTEGER) AS VOID OR Error
    PUBLIC FUNCTION Close(timeoutMs AS INTEGER) AS VOID OR Error
END CLASS

CLASS Client
    PUBLIC STATIC FUNCTION New(logger AS Log.Logger) AS Client OR Error
    PUBLIC FUNCTION Request(method AS STRING, url AS STRING, body AS STRING) AS Response OR Error
    PUBLIC FUNCTION Close() AS VOID OR Error
END CLASS
    PUBLIC STATIC FUNCTION FromPEM(certificatePem AS STRING, privateKeyPem AS STRING) AS TLSConfig OR Error
END CLASS

CLASS CookieJar
    PUBLIC FUNCTION Set(name, value, domain, path AS STRING, maxAgeMs AS INTEGER) AS VOID OR Error
    PUBLIC FUNCTION Get(name, domain, path AS STRING) AS STRING OR Error
    PUBLIC FUNCTION Delete(name, domain, path AS STRING) AS VOID OR Error
    PUBLIC FUNCTION Count() AS INTEGER
END CLASS

CLASS SessionStore
    PUBLIC STATIC FUNCTION New(capacity, idleMs AS INTEGER) AS SessionStore OR Error
    PUBLIC FUNCTION Create(value AS STRING) AS STRING OR Error
    PUBLIC FUNCTION Get(identifier AS STRING) AS STRING OR Error
    PUBLIC FUNCTION Set(identifier, value AS STRING) AS VOID OR Error
    PUBLIC FUNCTION Delete(identifier AS STRING) AS VOID OR Error
END CLASS

CLASS Scraper
    PUBLIC STATIC FUNCTION Parse(html AS STRING) AS Scraper OR Error
    PUBLIC FUNCTION Text(selector AS STRING) AS STRING OR Error
END CLASS

CLASS ACL
    PUBLIC FUNCTION Allow(cidr AS Net.CIDR) AS VOID OR Error
    PUBLIC FUNCTION Deny(cidr AS Net.CIDR) AS VOID OR Error
    PUBLIC FUNCTION Check(address AS Net.Address) AS BOOLEAN OR Error
END CLASS
```

Routes use decoded canonical paths. Literal segments outrank `:name`; route
registration order breaks ties. No match is `404`; a path match with the wrong
method is `405` with `Allow`. `HEAD` reuses `GET` routing without a response
body; `OPTIONS` returns the methods registered for the path. URL parsing rejects
controls, malformed escapes, encoded separators, dot segments, invalid UTF-8,
user information, unsupported schemes, and fragments. Filters are exposed by
`Server.AddFilter` with the synchronous typed signature above.

## Approval

Accepted for 0.3 implementation. Any further change requires updating this
document, the relevant normative 0.3 contract, and conformance fixtures.
