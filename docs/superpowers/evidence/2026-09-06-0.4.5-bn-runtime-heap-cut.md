# 0.4.5 runtime heap cut

## Scope

The checked generic heap is now owned by the `bn_runtime` workspace crate.
It depends only on `bn_diag` and `bn_source`; the root `bn` package keeps a
compatibility facade so the interpreter's existing `crate::heap` imports remain
stable.

The cut preserves allocation generation checks, bounds checks, zero-length
regions, destructor-phase deletion and stale-handle diagnostics. It does not
claim that the Executor, HOST providers, DataFrame implementation, HTTP or
network runtime have been extracted; those remain separate work under the
runtime and native-binding activities.
