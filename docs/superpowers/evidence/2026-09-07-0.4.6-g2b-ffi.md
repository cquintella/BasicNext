## Implemented Hardening

* Bounded column name length: Added MAX_COLUMN_NAME_LENGTH = 256. Scans view.name up to 257 bytes for a NUL terminator. If missing, null, or exceeding 256 bytes, returns BN_DATAFRAME_INVALID_ARGUMENT.
* Validated BNValueKind: Validates raw 4-byte discriminant at value address against BNValueKind::EndOfFile (0..=8) before union payload access. If outside range, copy_value fails safely and returns BN_DATAFRAME_INVALID_ARGUMENT.
* Safe boundary panic catches: Wrapped all public C ABI entry points (bn_rt_dataframe_create, bn_rt_dataframe_append_rows, bn_rt_dataframe_append_columns, bn_rt_dataframe_row_count, bn_rt_dataframe_column_count, bn_rt_dataframe_select, bn_rt_dataframe_close) in std::panic::catch_unwind returning BN_DATAFRAME_CONTRACT_ERROR on panic.
