# 0.4.5 evidence — IR-owned identities

Date: 2026-09-05

## Scope

The second implementation slice of bucket 0.4.5 Activity 2c.2 / WBS Activity
4.2 moves `SymbolId` and `ModuleId` into the public IR model. Frontend IDs are
converted explicitly during lowering; the interpreter, LLVM backend, provider
sets, and integration fixtures consume the IR-owned IDs.

`Type` remains a deliberate follow-up. Therefore GC-DEP and the hard crate split
are not claimed complete by this slice.

## Changes

- `src/ir/model.rs` defines `ir::SymbolId` and `ir::ModuleId`.
- `src/ir.rs` provides explicit frontend-to-IR conversions and converts module
  and symbol identities while lowering.
- LLVM and runtime consumers use the IR identity types.
- `tests/check-forbidden-deps.sh` prevents the public IR model from regressing
  to frontend `SymbolId`/`ModuleId` imports.
- The integration test compares provider identity through the explicit public
  conversion.
