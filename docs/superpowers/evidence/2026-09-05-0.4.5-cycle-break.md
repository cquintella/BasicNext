# 0.4.5 cycle-break slice — 2026-09-05

## Scope

The first implementation slice removes the DataFrame module's dependency on
the runtime-owned `Value` type. The DataFrame model is now generic over its
cell type; the runtime keeps local aliases for `DataFrame<Value>` and supplies
the existing `NotAvailable` predicate/value. This preserves the current
executor behavior while removing the `dataframe -> runtime` edge.

The HTTP cycle was audited in the same slice. `http.rs` defines the callback
type and consumes web state; it does not import runtime. Runtime still calls the
HTTP provider, which is a permitted runtime-to-host direction. No HTTP mutual
import was changed or claimed as fixed by this slice.
