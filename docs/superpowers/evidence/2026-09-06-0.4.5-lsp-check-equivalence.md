2. Execute `analyze_modules_with_warnings(&graph)`.
3. Execute `lower_graph_validated(&graph, &models)` so that language IR validation (`bn_ir::validate`) diagnostics are surfaced identically in both modes.
4. Convert diagnostics through the shared `bn_diag` catalog (`Catalog::global_for_environment().render(...)`).
