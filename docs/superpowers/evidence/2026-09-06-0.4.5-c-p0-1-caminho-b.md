- Goal: Retire fake placeholder return bodies (`RETURN 0`, `RETURN 0.0`, `RETURN ""`, `RETURN NEW DataFrame()`) in `modules/bn/BNData.bn` and `modules/bn/BNMath.bn`.
- Mechanism (Caminho B): Declarative intrinsic signatures with empty statement bodies in standard-library modules.
