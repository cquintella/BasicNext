# Filosofia do Basic Next

Basic Next busca legibilidade de BASIC sem abrir mão de tipos explícitos,
modularidade e mensagens de erro úteis.

1. O programa deve ser fácil de ler antes de ser fácil de abreviar.
2. Tipos estáticos são parte do contrato, não uma decoração opcional.
3. A biblioteca padrão resolve capacidades; palavras reservadas resolvem
   conceitos fundamentais da linguagem.
4. Uma nova palavra reservada só existe quando o conceito não puder ser
   expresso adequadamente pelas construções existentes ou por biblioteca.
5. A especificação precede a implementação e exemplos executáveis validam a
   especificação.
6. O projeto deve permitir implementação incremental em uma disciplina de
   Compiladores.
