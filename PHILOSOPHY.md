# Basic Next Philosophy

Basic Next is designed to reduce cognitive load and turn ideas into clear,
object-oriented, cross-platform software. Its design is informed by Zen:
clarity, restraint, and deliberate choices over novelty.

## Mission

Make modern programming more readable, predictable, and accessible through a
small, explicitly typed, object-oriented language.

## Vision

Enable people to create software for capable environments without sacrificing
readability, explicitness, portability, or creative freedom.

## Design principles

1. **Low cognitive load** — common code should be easy to understand.
2. **Readability first** — source code is communication, not merely an
   instruction to a machine.
3. **Ideas into software** — useful abstractions should be direct to express.
4. **Object-oriented by default** — behavior belongs to cohesive objects;
   dependencies and boundaries should be explicit.
5. **Keep it simple (KISS)** — prefer the simplest construct that expresses an
   idea clearly. Complexity must earn its place through a concrete problem,
   not anticipation.
6. **Clean by design** — the language should make Clean Code and Clean
   Architecture natural to apply, without imposing a framework or prescribed
   architecture.
7. **Small core, broad reach** — libraries and host capabilities provide
   features; reserved words express only fundamental language concepts.
8. **Cross-platform through capabilities** — programs target `HOST`
   capabilities, not vendors or operating systems.
9. **Explicit contracts** — types, boundaries, and effects should not be
   surprising.
10. **Deliberate evolution** — the specification precedes implementation;
    proposals, examples, simplicity, and compatibility outweigh novelty.
