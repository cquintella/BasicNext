# HOST.Net native parity and lifetime evidence

The native HOST.Net matrix is exercised by the CLI integration tests:

- `build-net-resolve.bn`
- `build-net-endpoint.bn`
- `build-net-udp-bind.bn`, `build-net-udp-close.bn`,
  `build-net-udp-send.bn`, `build-net-udp-receive.bn`, and
  `build-net-udp-packet.bn`
- `build-net-tcp-connect.bn`, `build-net-tcp-listen.bn`, and
  `build-net-tcp-accept.bn`

`cargo test --locked --test cli -- --test-threads=1` passed all 60 tests,
including native/interpreter parity for the listed fixtures and deterministic
EOF behavior.

The compiled runtime handle inventory is:

| Handle family | Create | Close/reuse | Invalid/stale behavior | Evidence |
| --- | --- | --- | --- | --- |
| UDP socket | `bn_rt_net_udp_bind` | `bn_rt_net_handle_close`; slot reusable | second close returns error | `crates/bn_rt/src/lib.rs` tests |
| TCP stream/listener | connect/listen/accept | same bounded handle table | invalid handle returns error | C ABI round-trip and EOF tests |
| UDP packet/buffer | receive-handle / buffer return | explicit packet/buffer free | stale handle rejected | packet-size/source/copy tests |

The `bn_rt` C ABI suite also passed its close, reuse, round-trip, and EOF
tests. No `unsafe` was added by this activity.
