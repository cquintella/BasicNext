# Bucket 0.4.5 — `bn_ir` crate cut

Date: 2026-09-06

## Implemented

- Moved the IR model, explicit `Phi`, `ValidatedModule` proof object and
  language validator into the standalone `bn_ir` crate.
- Kept lowering and semantic conversion in the root `ir` module, so `bn_ir`
  has no frontend or backend dependency.
- Made `bn_ir` depend only on `bn_diag`, `bn_source` and `bn_types`.
- Preserved the public root API by reexporting the crate's model and validator.
- Moved IR operand enumeration and duplicate-definition/CFG checks with the
  validator; no second validator or model remains in the root.
