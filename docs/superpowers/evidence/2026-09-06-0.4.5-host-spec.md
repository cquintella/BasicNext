# 0.4.5 evidence — HOST specification leaf

Date: 2026-09-06

## Result

The HOST member catalog is now owned by `src/host_spec/` as independent
descriptors (`SpecType`, `SpecMember`, and `Catalog`). Semantic analysis only
converts those descriptors into frontend types and allocates symbols. The old
`src/semantic/host_members1..4.rs` files and duplicated HOST entries in
`host_defaults.rs` were removed.

`host_spec` contains no runtime implementation imports. The dependency checker
also rejects a seeded semantic-to-`net` implementation import.
