# Bucket 0.4.5 — Diagnostic-typed FE→IR path

Date: 2026-09-06

## Decision

The FE→IR handoff is typed with `Diagnostic`. `lower_validated` and `lower_graph_validated` return `Result<ValidatedModule, Diagnostic>`, while `validate` and `validate_module` also return `Diagnostic` on rejection. This keeps language-invalid IR distinct from backend support failures.

LLVM text emission still has internal string failures for code-generation details; those are downstream of the validated handoff and are not used as the FE→IR error channel.
