# Roadmap

The roadmap describes small, verifiable deliveries; it is not a date promise.

The detailed 0.1 delivery plan is in [docs/project/WBS-0.1.md](docs/project/WBS-0.1.md).

1. **Language 0.1:** review and freeze the minimum specification and examples.
2. **Front end:** lexer, parser, AST, and syntax diagnostics.
3. **Semantics:** name resolution and type checking.
4. **Execution:** execute 0.1 programs using the engine selected at the
   architecture gate.
5. **Compilation:** choose and document a first backend, if compilation is
   pursued after interpretation.
6. **Standard library:** add capabilities only after the core language is
   stable.

Wasm, GUI, concurrency, ORM, embedded targets, GPU integration, and web DOM
integration are outside 0.1. Each begins as an independent proposal.
