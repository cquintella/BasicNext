# 0.4.5 evidence — explicit IR Phi and target support boundary

Date: 2026-09-06

## Result

AQ-20 is implemented for the current IR slice. `Instruction::Phi` carries a
destination, typed result, predecessor/value pairs and source span. Language
validation checks that incoming predecessors are exactly the reachable CFG
predecessors and that each incoming value is defined by its corresponding
predecessor. Existing branch-local value reuse remains valid; an explicit
`Phi` is required when a merged value is consumed across those paths.

The interpreter selects the incoming value using the actual predecessor block.
LLVM emits scalar `phi` instructions. Unsupported target constructs remain
support diagnostics rather than language-invalid IR.
