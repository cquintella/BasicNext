# Proposals

A proposal states motivation, examples, and grammar or semantic impact. Nothing
in this directory is part of the language until it is incorporated into the
specification.

- [C Foreign Function Interface](c-ffi.md) — proposed `HOST.c` capability and
  a deliberately narrow C ABI profile.
- [Checked Numeric Semantics](numeric-semantics.md) — proposed overflow,
  conversion, and allocation-size policy for Basic Next 0.1.
- [Scientific Standard-Library Surface](scientific-standard-library.md) —
  proposed `Time`, `Hash`, `Random`, and `Statistics` contracts for research.
