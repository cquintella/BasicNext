# 0.4.5 diagnostic model and sink

## Scope

`bn_diag` now provides the first production boundary for expressive
diagnostics:

- typed `DiagId` values with stable existing display codes;
- Rust-owned `Severity` and warning `Level` policy;
- `Label`/`LabelStyle` for primary and secondary spans;
- cheap `DiagnosticSpec` storage for unformatted emissions;
- `DiagnosticSink` filtering before storage and deduplication by
  `(DiagId, primary Span)`;
- hard diagnostics reject `allow` configuration.

The legacy `Diagnostic { code, message, span }` remains unchanged for
compatibility. Fluent catalogs, lazy rendering, call-site migration and full
registry/catalog completeness remain open and are not claimed by this slice.
