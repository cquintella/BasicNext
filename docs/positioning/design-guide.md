# Basic Next Design Guide

## Intent

Basic Next material should feel calm, precise, and welcoming: Zen restraint,
clean technical communication, a light retro-computing reference, and a
controlled rainbow accent. The visual identity supports the language promise:
reduce cognitive load without reducing expressive power.

## Visual system

- **Canvas:** warm paper `#F7F2E8`; never pure white by default.
- **Ink:** deep blue-black `#192330` for text and primary structure.
- **Structure:** midnight blue `#13212E` for title bands and strong anchors.
- **Accents:** teal `#2AA198`, violet `#7C5CE0`, gold `#E9B949`, and coral
  `#E76F51`.
- **Rainbow rule:** use the four accents only as a thin horizontal spectrum,
  small markers, or category labels. Never use a large gradient, rainbow text,
  or more than one major accent in a page section.

## Typography and layout

- Use a clean sans-serif for titles and body text; use a monospaced face only
  for code, commands, and short technical labels.
- Prefer short paragraphs, generous margins, strong headings, and one main
  idea per page region.
- Use A4 portrait for papers. Keep title pages spacious; use compact, readable
  comparison tables rather than dense prose.
- Code uses a pale blue-gray panel and dark monospaced text. It must never be
  used as a decorative texture.

## Voice

Write plainly and confidently. Describe current facts separately from future
direction. Avoid hype, benchmark claims, vendor hostility, and claims that BN
is already production-ready. The project is pre-implementation; its strength
today is a deliberate language design and an open specification.

## Signature line

> Clear ideas. Explicit contracts. Broad reach.
