# Bucket 0.4.5 — short-circuit SSA repair

Date: 2026-09-06

## Root cause and implementation

`Builder::short_circuit` previously defined one destination in both the short
path and the right-hand path. That violated the locked single-assignment IR
contract as soon as duplicate-definition validation was enabled. The lowering
now gives each path its own value and emits one explicit `Phi` at the join for
the expression's result.
