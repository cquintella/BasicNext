The `bnc` binary is delivered as a lightweight pipeline manager and execution controller invoking `bn` as the underlying engine.

## Implementation Details

1. **Binary Target:**
   - Registered `[[bin]] name = "bnc" path = "src/bnc.rs"` in root `Cargo.toml`.
   - Thin dispatch implementation in `src/bnc.rs`.
2. **UX Alignment:**
   - Default: `bnc <entry.bn>` executes interpreted via `bn run`.
   - Compile: `bnc -c <entry.bn>` builds for host via `bn build`.
   - Target Compile: `bnc -c --target <plat> <entry.bn>` builds for platform (e.g. `wasm32`, `native`).
   - Check: `bnc --check <entry.bn>` validates analysis/IR via `bn check`.
   - Option enforcement: mutually exclusive flags (`-c` with `--check`), required pairs (`--target` requires `-c`).
   - Logging forwarding: `--log-level`, `--log-file`, `--log-dir`, `--no-log`. Default companion log for compile mode.
3. **Integration Test Suite:**
   - Created `tests/bnc.rs` with 8 comprehensive integration test cases:
     - `bnc_help_succeeds`
     - `bnc_version_succeeds`
     - `bnc_missing_entry_fails`
     - `bnc_conflicting_compile_and_check_fails`
     - `bnc_target_without_compile_fails`
