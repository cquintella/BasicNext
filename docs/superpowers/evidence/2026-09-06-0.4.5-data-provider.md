# Bucket 0.4.5 — DataProvider injection slice

Date: 2026-09-06

## Implemented

- Added the public `bn_rt::DataProvider` trait for the standard-library data
  boundary and re-exported it from `runtime` for compatibility.
- Added `bn_rt::StandardDataProvider`, backed by the shared
  `bn_rt::parse_csv` implementation, and made it the default `HostEnv`
  provider.
- Added `HostEnv::with_data_provider` and preserved provider identity across
  `HostEnv::clone` and task forks.
- Changed `BNData.ReadCSV` to call the injected provider after filesystem
  access, instead of selecting the CSV parser directly in the Executor.
- Moved generic `AppendRows` and `AppendColumns` schema/shape operations into
  `bn_rt`; the interpreter supplies only `Value`-specific missing-value and
  type-identity predicates.
- Moved the generic `Select` row/column projection and its bounds/duplicate
  label checks into `bn_rt`; the interpreter now retains only argument
  conversion, handle allocation and language-level error projection.
- Added the first stable `bn_rt` DataFrame ABI layer: copied column views,
  opaque `u64` frame handles, structural append/select operations, close
  invalidation, row/column count queries and explicit status codes. It is
  used by the compiled backend for the empty-frame lifecycle slice; the
  remaining DataFrame APIs are not advertised as compiled support.
- Added LLVM lowering for the BNData empty-frame lifecycle: construction,
  `RowCount`, `ColumnCount` and `DELETE` call the same `bn_rt_*` symbols used
  by the ABI, with status failures routed to the runtime trap.
- Kept DataFrame construction and handle ownership in the interpreter until
  their individual native ABI contracts are complete.
- Moved DataFrame column/matrix transformation and statistical reduction operations
  into pure primitives in `bn_rt`: `set_column_label`, `transpose_dataframe`,
  `add_dataframe_column`, `column_name`, `get_dataframe_cell`, `convert_dataframe_column`,
  `zscore_column`, `dataframe_reduce_column`, and `copy_dataframe_column`.
- Re-routed Executor handlers in `part9.rs` and `part13.rs` to call these `bn_rt` functions,
  slimming the interpreter DataFrame specializations and eliminating duplicate stats logic.

This completes C-P1.1 (D4). The empty-frame lifecycle is compiled through the

the HostEnv injection, handle ownership, and compatibility re-exports.
