## 1. Findings Verification & Closure

* **Activity 5.1: BN-SEC-001/002 SSRF evidence**
  * `BN-SEC-001`: IPv4-mapped IPv6 reclassified as IPv4.
    * Tested in `src/web/tests.rs::ssrf_guard_reclassifies_ipv4_mapped_ipv6_as_ipv4`.
  * `BN-SEC-002`: Rejection of special/CGNAT/private ranges while allowing global IPv4.
    * Tested in `src/web/tests.rs::ssrf_guard_rejects_special_ipv4_ranges_but_allows_global_ipv4`.

* **Activity 5.2: F-07 503 on admit failure**
  * In `src/http.rs::route_response`, when concurrency permit exhaustion or worker admission fails, the server records a failure and returns `StatusCode::SERVICE_UNAVAILABLE` (503 "handler queue is full").
  * Tested in `src/http/tests.rs::opt_in_concurrent_handler_rejects_when_global_slot_is_occupied`.

* **Activity 5.3: F-09 macOS keychain PEM clean-up**
  * Removed non-PEM binary Keychain path `/System/Library/Keychains/SystemRootCertificates.keychain` from `src/tls.rs` candidate list.
  * Preserves standard PEM bundles `/etc/ssl/cert.pem` and `/etc/ssl/certs/ca-certificates.crt`.
  * Tested in `src/tls.rs::tests::client_config_uses_a_system_trust_store_when_available`.

* **Activity 5.3: F-10 arp/ndp PATH hijack mitigation**
  * In `src/net/neighbor.rs`, replaced ambient PATH invocation of `arp` and `ndp` with trusted absolute system binary resolution (`/usr/sbin/arp`, `/usr/bin/arp`, `/sbin/arp`, `/usr/sbin/ndp`, `/usr/bin/ndp`).
  * Rejects ambient/untrusted commands.
  * Tested in `src/net/neighbor.rs::tests::resolve_trusted_program_rejects_untrusted_names_and_paths`.

## 2. Residuals Disposition

* `R-01`: SSRF DNS rebinding and redirect limits. Owner: Doug. Risk: a future
  resolver or redirect integration could bypass per-hop revalidation.
  Defer-until: the next BNWeb security review after the 0.4 release. Current
  behavior re-resolves and validates the allowlist on each hop.
* `R-02`: In-memory session store lifecycle. Owner: Doug. Risk: sessions are
  lost on restart and cannot be shared across processes. Defer-until: a
  versioned distributed-session-store proposal is accepted.
* `R-03`: OS kernel socket backlog and file-descriptor quotas. Owner: Doug.
  Risk: deployment limits below configured bounds can reject work earlier.
  Defer-until: deployment evidence review for each release target.
