# Bucket 0.4.5 — Execution policy carrier, defaults, and boundary checks (C-P1.3 / D6)

Date: 2026-09-06

## Architectural decision & carrier choice

As locked in `docs/architecture/host-traits.md` and approved for AQ-17:

- **Carrier Choice**: Alternative C (versioned compile-time ceiling embedded into the compiled artifact).
- **Compile-time Emission**: In `crates/bn_llvm/src/llvm/functions.rs`, the entry block of the `Start` function calculates the module's policy requirements via `policy_ceiling(module)` and emits `call i32 @bn_rt_policy_init(i32 1, i64 {ceiling})`.
- **Runtime Restriction & Monotonicity**: At launch or during execution, runtime restrictions can only narrow permissions via `bn_rt_policy_restrict(mask)`. The effective policy is maintained in `crates/bn_rt/src/policy.rs` via atomic bitwise intersections (`CEILING.fetch_and(...)`, `EFFECTIVE.fetch_and(...)`). Neither embedders nor launch environments can widen the compile-time ceiling.
- **Boundary Enforcement**: Sensitive runtime calls in `bn_rt` (Console, Network, Dispatch, FileSystem) perform call-boundary checks (`allows(...)`). If an unauthorized call is attempted, `bn_rt` writes `error[EXECUTION_POLICY_DENIED]: ...` to stderr and returns error status code 2 (`POLICY_INVALID` / denied).

## Three-way error and exit code taxonomy

The system strictly distinguishes three categories of failures:

1. **Language-Invalid IR**:
   - Detected during semantic validation or IR validation (`crates/bn_ir/src/validate.rs`).
   - Yields diagnostic codes like `INVALID_IR_*`, `TYPE_MISMATCH`, etc.
   - Result: Exit code 1 (Language error).
2. **Target-Unsupported IR**:
   - Detected during `validate_for` / support checks (e.g., `TARGET_UNSUPPORTED_*`).
   - Rejects at check/build time without producing or running invalid native artifacts.
   - Result: Exit code 2 (Tool error).
3. **Execution Policy Denied**:
   - Valid IR and supported backend, but runtime execution policy denies the requested operation.
   - Handled in interpreter (`src/main.rs`) and compiled runtime (`crates/bn_rt/src/policy.rs`).
   - Produces diagnostic `EXECUTION_POLICY_DENIED`.
   - Result: Exit code 2 (Tool error / policy failure), distinct from language semantic failure.
