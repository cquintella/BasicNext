# 0.4.5 src/ cleanup and GATE G6 (src-clean) evidence

## Summary

This document records the completion of Section 6 activities (6.1–6.5) and the closing of GATE G6 (src-clean) for BasicNext 0.4.5.

## Activity 6.1 & 6.4 — Inventory and facade policy

Every Rust file under `src/` is inventoried and classified according to the Section 6 contract:

### Category A: Thin facade / wiring (allowlisted)
- `src/main.rs`: CLI dispatcher, options parsing, process log driver, invocation wiring.
- `src/lib.rs`: Root crate facade re-exporting `bn_frontend`, `bn_source`, `bn_types`, `bn_diag`, `bn_ir`, `bn_llvm`, and internal facades.
- `src/cli_frontend.rs`: CLI argument parsing.
- `src/cli_help.rs`: CLI help and usage formatters.
- `src/cli_output.rs`: Terminal output printer.
- `src/cli_toolchain.rs`: Environment and compiler toolchain discovery.
- `src/process_log.rs`: Structured build pipeline event recorder.
- `src/heap.rs`: 4-line compatibility facade re-exporting `bn_runtime::{Handle, Heap}`.
- `src/ir.rs`: 9-line compatibility facade re-exporting `bn_ir` model and `bn_frontend::lowering`.
- `src/llvm.rs`: 6-line compatibility facade re-exporting `bn_llvm`.
- `src/dataframe.rs`: 14-line compatibility facade re-exporting `bn_rt::dataframe`.
- `src/runtime.rs`: 2-line module facade (`include!("runtime_impl.rs");`).

### Category B: Retained root logic (planned for post-0.4.5 extracts)
- Runtime execution engine: `src/runtime_impl.rs`, `src/runtime/allocation.rs`, `src/runtime/collections.rs`, `src/runtime/compare.rs`, `src/runtime/executor.rs`, `src/runtime/executor/*.rs`, `src/runtime/helpers.rs`, `src/runtime/math.rs`, `src/runtime/net_values.rs`, `src/runtime/numeric.rs`, `src/runtime/render.rs`, `src/runtime/support.rs`, `src/runtime/temporal_ops.rs` (scheduled for XM9 `bn_runtime`).
- Task and concurrency dispatch: `src/dispatch.rs`, `src/dispatch/sync.rs`.
- IDE protocols: `src/dap.rs`, `src/lsp.rs`, `src/lsp/completion.rs` (scheduled for XM11 `bn-dap` / `bn-lsp`).
- Host services: `src/http.rs`, `src/web.rs`, `src/web_state.rs`, `src/web/routing.rs`, `src/web/server.rs`, `src/net.rs`, `src/net/icmp.rs`, `src/net/neighbor.rs`, `src/net/reverse.rs`, `src/tls.rs` (scheduled for XM9 `bn_host_*`).
- Common helpers: `src/config.rs`, `src/json.rs`, `src/log.rs`, `src/temporal.rs`.
