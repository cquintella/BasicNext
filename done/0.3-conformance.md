# Basic Next 0.3 conformance evidence

This record captures the local release checks for the 0.3 gate.

## Executable checks

- `cargo fmt --check` — passed.
- `cargo test --all-targets --quiet` — passed (all suites).
- `cargo clippy --all-targets -- -D warnings` — passed.
- `git diff --check` — passed.
- `examples/socket.bn --help` — passed.
- `socket_examples_exchange_tcp_and_udp_messages` — passed for TCP and UDP on
  IPv4 and IPv6 loopback; each server invocation writes its accepted-connection
  record through `BNLog`.
- `examples/icmp-ping.bn` — passes static checking. It is a manual diagnostic
  for `www.intelliurb.com`, excluded from release checks because D-016 specifies
  deterministic ICMP operation-unavailable behavior on the current macOS host.
- Every `modules/bn/*.bn` file passes `cargo run -- check`.
- VS Code syntax, extension, and debug-adapter checks pass with Node.js.
- The Jupyter wire suite is provider-gated: `pyzmq` is not installed in this
  environment, so the suite reports the documented unavailable-provider
  condition rather than making a support claim.

## Support boundaries

Windows console evidence is inherited from the 0.2 audit as specified by the
0.3 WBS. No new Windows capability claim is made without a native console run.
Wasm, compiler, and Jupyter debugging remain unavailable without providers.
