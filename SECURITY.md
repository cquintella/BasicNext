# Security policy

## Supported versions

Security fixes are made on the current release line. Older releases may be
useful for historical language compatibility, but they do not receive security
updates.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
private vulnerability reporting for this repository. If that option is not
available, contact the maintainer using the address listed in
[`docs/sponsorship.md`](docs/sponsorship.md) and include `Basic Next security`
in the subject.

Include the affected version or commit, platform, impact, reproduction steps,
and any proposed mitigation. Do not include real credentials, personal data,
or destructive proof-of-concept payloads.

Reports will be acknowledged as soon as practical. A remediation timeline will
be set after severity and release impact are confirmed.
