# Basic Next 0.6.2 — verified installers and Rust test harness

**Tag:** `v0.6.2` (pending publication).
**Base:** 0.6.1.

## Highlights

- **Native Windows bootstrap.** `install.ps1` resolves a release, downloads
  its assets with PowerShell, verifies SHA-256 checksums, extracts the
  versioned ZIP payload, and installs without requiring `curl.exe`, `tar.exe`,
  or a source checkout.
- **Versioned release support files.** Releases include both installers,
  source payloads in `.tar.gz` and `.zip` formats, man pages, and one
  `SHA256SUMS` manifest covering every published asset.
- **Rust-only active test harness.** Compiler parity, target capabilities,
  Wasm parity, LSP protocol, PTY behavior, and support-matrix reporting no
  longer depend on Python.
- **Supply-chain gates.** CI rejects floating GitHub Action references,
  unverified LLVM repository keys, mutable-branch installer execution, and
  release layouts missing checksummed support assets.

## Compatibility and exclusions

The Basic Next language surface is unchanged from 0.6.1. Installed commands
remain `bni` and `bnc`. This release does not include BNSqlite; that module is
scheduled for 0.6.3.

## Verification

The release gate includes the complete Rust workspace tests, Clippy with
warnings denied, formatting, dependency and language-policy checks, the
support-matrix report, Unix installer checks, and the real Windows installer
integration scenario on PowerShell 5.1 and PowerShell 7.
