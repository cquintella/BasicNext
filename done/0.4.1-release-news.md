# Basic Next 0.4.1 Release Notes

Basic Next 0.4.1 is a hardening and conformance patch release for the 0.4
Rust reference frontend and native host providers.

## BNDispatch recovery

- Queue workers disconnect and join within bounded close deadlines.
- Pending cancellation prevents user-code entry.
- Worker panics become failed tickets without killing the worker pool.
- Pending-ticket capacity excludes terminal tickets.
- Barrier timeouts break only the affected generation.
- Mutex, semaphore, and group misuse returns typed errors.
- Poisoned synchronization state no longer aborts the process.
- Self-join from a dispatch worker returns `SelfJoin`.
- Ticket IDs are CSPRNG-backed and non-sequential.
- Async tasks use independent runtime and host random state, with regression
  coverage for BN-DISPATCH-009.

## Native networking hardening

- Resolver timeout tasks retain join handles for later reaping.
- TCP connect applies its timeout to subsequent reads and writes.
- TCP listeners use the requested backlog.
- TCP accept uses a bounded asynchronous timeout instead of fixed busy polling.
- TCP, UDP, and listener handles share a configured socket quota.
- Resolver results and UDP datagrams use registry-backed limits.
- IPv4-mapped IPv6 addresses follow IPv4 private/loopback classification.
- UDP multicast and broadcast destinations are denied.

`Ping`, `Neighbor`, and `Reverse` remain provider-deferred and return a
deterministic unavailable-provider result until a platform provider contract
defines permissions, deadlines, and output semantics.

## Verification

The release tree passed `cargo test --all-targets`,
`cargo clippy --all-targets -- -D warnings`, and `cargo fmt --check`. VS Code
adapter checks and the Jupyter Program/wire tests also passed.
