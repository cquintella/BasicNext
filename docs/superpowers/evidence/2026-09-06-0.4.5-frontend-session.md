# Bucket 0.4.5 — FrontendSession progress

Date: 2026-09-06

## Implemented

- Added shared `SourceId` and per-source monotonic `Revision` values in `source`.
- Added `FrontendSession` snapshot storage for disk or unsaved-buffer text.
- Added reverse import edges and transitive invalidation when a source is replaced.
- Added revision checks that discard results from an older analysis request.
