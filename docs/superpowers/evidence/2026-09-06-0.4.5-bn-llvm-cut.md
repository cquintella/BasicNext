# 0.4.5 LLVM backend cut

## Scope

The textual LLVM backend is now owned by the `bn_llvm` workspace crate. Its
normal dependencies are limited to `bn_diag`, `bn_ir`, `bn_source` and
`bn_types`; it has no dependency on the frontend, interpreter runtime or root
`bn` package. The root `src/llvm.rs` is a compatibility facade.

The backend continues to consume `ValidatedModule` and keeps language
validation separate from `validate_for(target)`. Existing LLVM lowering,
support diagnostics, host declarations and optimization behavior were moved
without changing their public root paths.
