# Basic Next 0.3 Vector and LLVM Contract Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task with verification checkpoints.

**Goal:** Align declaration-time vector dimensions, numeric LLVM types, explicit CFG lowering, and IR test construction with the accepted 0.3 contract.

**Architecture:** Extend the AST and IR with an explicit dimension-expression operand while preserving literal dimensions for signatures and fields. Replace constant-program evaluation as the LLVM build path with typed block/instruction lowering and explicit failure for unsupported operations. Keep interpreter overflow and backend overflow diagnostics under the same error code.

**Tech Stack:** Rust 2024, handwritten lexer/parser, typed semantic model, BN IR, textual LLVM IR, Cargo integration tests.

**Spec:** `docs/superpowers/specs/2026-08-31-0.3-vector-llvm-contract-design.md`

## Global Constraints

- Preserve source spans through parser, semantic, IR, and diagnostics.
- No unsafe Rust and no new production dependency.
- Local declaration dimensions may be expressions; parameters, fields, and returns remain literal-only.
- `INTEGER/INT32 → i32`, `BYTE → i8`, `UINT64 → i64`, `FLOAT32 → float`, `FLOAT64 → double`.
- Unsupported LLVM lowering returns `BUILD_LOWERING_UNAVAILABLE`.
- Run `cargo fmt --check`, affected tests, `cargo clippy -- -D warnings`, and `git diff --check`.
